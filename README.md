# i_love_digits

Recognizing handwritten digits on FPGA.

## Vivado project initialization

1. Launch Vivado v2024.2.
2. Using `Tools -> Run Tcl Script...` run [`i_love_digits.tcl`](i_love_digits.tcl).

### Committing changes

1. Install https://github.com/barbedo/vivado-git.
2. Run `wproj` command in Vivado Tcl Console. This will regenerate [`i_love_digits.tcl`](i_love_digits.tcl).
3. Commit.
